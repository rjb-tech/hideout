# Portfolio

I've always had the goal to keep a side project or two going in addition to my day job. It's gotten much harder as I've leveled up and taken on more responsibility at work, but I find that taking the time to build something based on an idea I came up with keeps the magic alive in this profession. It's like the most accessible lego set ever. There aren't a ton of impossible ideas. While I'm proud of the work I've done in my professional life, I believe this portfolio gives equal if not better insight into my abilities when compared to my formal resume (found here). All of these projects have been deployed to a production environment at some point with some still deployed.
